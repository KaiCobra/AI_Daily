## SANA-Video 2.0: Hybrid Linear Attention with Attention Residuals for Efficient Video Generation

### 核心貢獻與創新點

在影片生成領域，傳統的 Diffusion Transformer (DiT) 依賴完整的 3D Softmax Attention，這會帶來 $O(N^2)$ 的計算複雜度。對於高解析度或長影片而言，這項計算成本是難以承受的。另一方面，純線性注意力 (Pure Linear Attention) 雖然具備 $O(N)$ 的優良擴展性，但因為固定大小的狀態矩陣存在秩限制 (rank bottleneck)，無法精確表達所有 token 之間的互動，進而導致時空一致性和細節生成的品質下降。

為了打破這種「效率與表達能力」的兩難，NVIDIA 團隊推出了 **SANA-Video 2.0**，這是一個 5B 和 14B 參數規模的混合注意力影片擴散模型 (Hybrid Video Diffusion Transformer)。其核心貢獻如下：

1. **Hybrid Linear-Softmax Attention**：將門控線性注意力 (Gated Linear Attention) 與週期性的門控 Softmax 錨點 (Gated Softmax Anchors) 以 3:1 的比例混合 (即 75% 線性，25% Softmax)。這在保持 $O(N)$ 計算主導地位的同時，恢復了純線性注意力所缺乏的全秩 (full-rank) token 互動。
2. **Block Attention Residuals (AttnRes)**：為了解決後續線性層需要重新推導上游特徵的問題，引入了 AttnRes 機制。該機制將已完成的區塊摘要 (Block Summaries) 跨深度路由至後續的線性層，實現了錨點特徵的重用，並將深層有效秩 (effective rank) 提升了約 12%。
3. **From-Scratch Training 與高效部署**：有別於對預訓練 Softmax 模型進行後線性化 (post-hoc linearization)，SANA-Video 2.0 是從頭開始訓練的。結合 Sol-Engine 的全端最佳化（算子融合、快取和稀疏注意力），5B 模型在單張 H100 上生成 720p/5s 影片僅需 13.06 秒，速度是同級模型的數十倍。

### 技術方法簡述

SANA-Video 2.0 的架構設計精巧地結合了線性注意力的高效與 Softmax 注意力的精準。

#### 1. Hybrid Linear-Softmax Attention

模型以雙向門控雙線性注意力 (Bidirectional Gated Bilinear Attention) 作為核心的 token 混合操作。對於標準化的 Query 和 Key，令 $q_j^r, k_n^r$ 表示經過 RoPE 旋轉後的特徵，$\phi(\cdot) = \operatorname{ReLU}(\cdot)$。每個注意力頭的計算公式為：

$$
S = \sum_n v_n (\beta_n k_n^r)^\top, \qquad o_j = W_o \!\left[ \operatorname{RMSNorm}\!\left( \frac{S q_j^r}{\sum_n \phi(k_n)^\top \phi(q_j) + \epsilon} \right) \odot \sigma(g_j) \right]
$$

其中，$\beta$ 是寫入狀態的門控，$g$ 是輸出門控。

為了彌補線性注意力的表達能力不足，模型每隔四層插入一個 Softmax Anchor (即 3:1 比例)。這些 Anchor 使用帶有 QK 正規化和 RoPE 的雙向 SDPA，並結合 Sigmoid 輸出門控。這種混合設計在維持整體 $O(N)$ 複雜度的同時，週期性地注入精確的注意力矩陣。

#### 2. Block Attention Residuals (AttnRes)

傳統的殘差連接 $h_l = h_{l-1} + f_l(h_{l-1})$ 只能逐層傳遞資訊。SANA-Video 2.0 採用了 Block AttnRes，將每 8 層 (包含兩次 Softmax Anchor 循環) 視為一個 Block。當一個 Block 運算完成時，其累積的特徵會被凍結為一個完成的摘要 $b_k$。

在第 $l$ 層，路由器 (Router) 會從一個包含初始 token 嵌入 $b_0$、已完成的 Block 摘要 $b_1, b_2, \dots$ 以及當前 Block 的部分和 $p_l$ 的來源集合 $\mathcal{V}_l$ 中提取資訊。對於每個 token $x$，進入注意力層或 FFN 層 ($\tau \in \{\mathrm{attn}, \mathrm{ffn}\}$) 前的特徵 $h_l(x)$ 計算如下：

$$
h_l(x) = \sum_{v_i \in \mathcal{V}_l} \alpha^{(\tau)}_{i \to l}(x) \, v_i(x), \qquad \alpha^{(\tau)}_{i \to l}(x) = \operatorname*{softmax}_i \!\Big( \big( w^{(\tau)} \big)^{\!\top} \operatorname{RMSNorm}(v_i(x)) \Big)
$$

為了適應影片擴散模型，SANA-Video 2.0 讓所有層共享同一個注意力查詢 $w^{(\mathrm{attn})}$ 和 FFN 查詢 $w^{(\mathrm{ffn})}$，這大幅減少了參數，同時依然能根據深度的不同自適應地調整路由權重。

### 實驗結果與性能指標

SANA-Video 2.0 在多項指標上展現了卓越的性能，特別是在生成品質與推理效率的權衡上。

1. **VBench 影片生成品質**：
   在 480x832x81 的解析度下，SANA-Video 2.0 (5B) 在 VBench 上取得了 **84.30** 的總分，這與擁有 14B 參數的 Wan 2.1 (83.69) 和 Bernini-R (84.64) 處於同一水準，甚至在品質分數 (Quality Score, 85.61) 上超越了許多全 Softmax 模型。

![VBench 比較表格](../../../../asset/SANA-Video-2.0/table2_vbench.png)
*表 2：VBench 品質比較。SANA-Video 2.0 (5B) 在品質指標上名列前茅。*

2. **推理效率與擴展性**：
   得益於 $O(N)$ 主導的混合注意力，5B 模型在單張 H100 上生成上述影片僅需 13.2 秒，而全 Softmax 模型的耗時高達 421 秒 (快了約 31.8 倍)。在 720p/60s 的長影片測試中，編譯後的 DiT 前向傳播速度比全 Softmax 基線快了 **3.2 倍**，且這個優勢隨著影片長度的增加而持續擴大。

![效率與擴展性比較](../../../../asset/SANA-Video-2.0/fig5_efficiency_scaling.png)
*圖 5：效率擴展性分析。隨著序列長度增加，25% Softmax 混合架構的延遲顯著低於全 Softmax 模型。*

3. **架構消融實驗 (Softmax Ratio)**：
   研究團隊透過代理實驗測試了不同 Softmax 比例的影響。結果顯示，25% (3:1) 的 Softmax 比例是一個完美的 Pareto 最優點 (Pareto knee)。純線性注意力 (0%) 的驗證損失最高 (0.955)，而全 Softmax (100%) 的損失 (0.945) 甚至不如混合架構。25% 的比例在極大降低延遲的同時，達到了最低的驗證損失 (0.905)。

### 相關研究背景

本研究巧妙地融合了兩個領域的最新進展：
1. **影片生成中的 Flow Matching 與 DiT**：如 Wan 2.1 和 HunyuanVideo 等最新模型均採用了 Flow Matching 和 DiT 架構，但受限於 Softmax 的二次方複雜度。
2. **大型語言模型 (LLM) 的線性與混合注意力**：如 Qwen3-Next 和 Kimi-Linear 探索了在 LLM 中混用線性與 Softmax 注意力。SANA-Video 2.0 首次將這種架構 (包含 Kimi 團隊提出的 Attention Residuals) 成功且從頭訓練地應用於超大規模的影片生成任務中，證明了 LLM 的高效擴展原則同樣適用於 AIGC Foundation Models (AFMs)。

### 個人評價與意義

SANA-Video 2.0 是一篇極具工程啟發性和學術價值的論文。

首先，它完美回應了「**Attention Modulation**」的理念。它不是盲目地拋棄 Softmax，而是將其作為一種「錨點 (Anchor)」，用來定期修正和刷新線性注意力的狀態。這種 3:1 的混合比例設計，既享受了線性注意力 $O(N)$ 的速度紅利，又保證了生成細節的精確度。

其次，**Block Attention Residuals (AttnRes)** 的引入是神來之筆。在影像或影片生成中，深層網路往往會面臨特徵退化或秩崩塌的問題。透過跨深度路由將高質量的 Softmax 錨點特徵直接傳遞給後續的線性層，不僅提升了深層的有效秩，還避免了重複計算。

最後，這篇論文證明了 **Training-free 的推論加速與 From-scratch 的架構創新必須並行**。雖然許多研究致力於在推論階段無須訓練地修改注意力機制，但 SANA-Video 2.0 選擇從頭訓練一個硬體友善的混合架構，並配合 Sol-Engine 的極致最佳化，最終在單卡 H100 上實現了 13 秒生成 720p 影片的驚人成績。這為未來「在消費級硬體上運行高品質長影片生成」指明了一條非常務實的道路，強烈推薦深入閱讀其原始程式碼與訓練細節。
